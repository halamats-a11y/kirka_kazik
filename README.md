# ⛏ Кирка — версия для iPhone

Шахтёрское казино в стиле Майнкрафта. Без реальных денег: монеты виртуальные.

**Играть:** открой ссылку GitHub Pages этого репозитория в **Safari** на iPhone → кнопка «Поделиться» ⬆︎ → «На экран „Домой“».

Файлы созданы скриптом `make-iphone.py` из основного проекта. Не правь их руками: поменяй игру и запусти скрипт ещё раз.
